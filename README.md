# UkrSibKeyTool

Невеликий Windows-застосунок для роботи з RSA-ключами, потрібними для підключення до **UKRSIB business API** (використання ключа в 1С через `RSACryptoServiceProvider.FromXmlString`).

![version](https://img.shields.io/github/v/release/Pro100NeFarT/UkrSibKeyTool)

## Можливості

- **Генерація нового RSA-4096 ключа** — так само, як у власній інструкції банку (`openssl genpkey` → `pkcs8 -nocrypt`), але без залежності від OpenSSL: реалізовано на чистому .NET, перевірено на бітову сумісність з ключами, згенерованими самим `openssl`.
- **Конвертація приватного ключа (`.pem`) у XML** — рядок для вставки в `мПриватныйКлючXML()` у модулі 1С. Підтримує:
  - звичайний незашифрований PKCS8/PKCS1 ключ;
  - сучасний зашифрований PKCS8 (`-----BEGIN ENCRYPTED PRIVATE KEY-----`);
  - старий формат PKCS1 з `Proc-Type: 4,ENCRYPTED` (через локальний `openssl`, якщо він є на машині — наприклад, з Git for Windows).
- **Формування листа до банку** — тема й текст листа для підключення до API, з полем назви системи, готові скопіювати.
- **Автооновлення** — кнопка з версією перевіряє останній реліз на GitHub і за потреби оновлює застосунок в один клік.
- **Діагностичний лог** (опційний) — для діагностики проблем з розшифруванням/паролем, переглядається прямо в застосунку.

## Встановлення

Зайдіть на сторінку [Releases](https://github.com/Pro100NeFarT/UkrSibKeyTool/releases) і завантажте один з варіантів — `.NET` встановлювати не потрібно в обох випадках, адміністраторські права теж не потрібні:

- **`UkrSibKeyTool-Setup-X.Y.Z.exe`** (рекомендовано) — звичайний інсталятор. Ставить застосунок у профіль поточного користувача (`%LocalAppData%\Programs\UkrSibKeyTool`), додає ярлик на робочий стіл і в меню "Пуск", реєструє видалення через "Програми і компоненти". Мова інсталятора — українська (є й англійська).
- **`UkrSibKeyTool-portable-win-x64.zip`** — без інсталяції: розпакуйте в будь-яку папку і запускайте `UkrSibKeyTool.exe` звідти. Зручно, якщо не можна нічого встановлювати, або для разового використання/тесту.

Оскільки файли не підписані сертифікатом, Windows SmartScreen може показати "Windows захистила ваш ПК" при першому запуску — натисніть «Докладніше» → «Виконати попри це».

> Для генерації нового ключа й конвертації в XML зовнішні залежності не потрібні. `openssl` (Git for Windows або окремо встановлений) потрібен лише якщо ви імпортуєте **вже існуючий** ключ старого зашифрованого формату (`Proc-Type: 4,ENCRYPTED`).

## Типовий сценарій

1. Натисніть **«Згенерувати новий ключ...»**, оберіть, куди зберегти приватний і відкритий ключ.
2. Вкажіть назву вашої системи, натисніть **«Сформувати текст листа»** і надішліть банку (з прикріпленим відкритим ключем).
3. У відповідь банк надішле `Client_ID` та `Client_secret`.
4. Натисніть **«Конвертувати в XML»** — отриманий рядок вставте в `мПриватныйКлючXML()` у 1С.

## Розробка

Проєкт на .NET 8 (WinForms, `net8.0-windows`). Збірка:

```
dotnet build -c Release
```

Портативна версія (папка, самодостатня, без залежності від .NET на цільовій машині):

```
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=false
```

Інсталятор (потрібен [Inno Setup 6](https://jrsoftware.org/isinfo.php)) — спочатку зібрати портативну версію командою вище, потім:

```
"C:\Users\<user>\AppData\Local\Programs\Inno Setup 6\ISCC.exe" installer\UkrSibKeyTool.iss
```

Результат — `installer-output\UkrSibKeyTool-Setup-X.Y.Z.exe`.
